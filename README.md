# prisma-launcher-updates

## Distribuição automática PRISMA

Este repositório público distribui apenas o APK assinado e o arquivo `latest.json`. O código-fonte e a chave de assinatura permanecem no repositório privado.

Configure **Settings → Pages → Deploy from a branch → main → /docs** após a primeira publicação.

Canal esperado: https://johnattor.github.io/prisma-launcher-updates/latest.json
